# Chameleon и антивирусы: честно о ложных срабатываниях

> **Коротко:** `Chameleon.exe` не содержит вирусов. Предупреждения антивирусов — ложные срабатывания эвристик, и это известная особенность всех программ на Python, собранных в один exe-файл. Ниже — простое объяснение «почему» и пять минут на самостоятельную проверку.

## Сначала главное

- **Программа открытая.** Весь код лежит в репозитории: его можно прочитать, а можно вообще не читать — просто собрать программу самому из исходников. Это надёжнее любых заверений разработчика.
- **Делает она ровно одно:** собирает VPK-архив с косметическими модами для Dota 2. Не внедряется в игру, не трогает исполняемые файлы, ничего не устанавливает в систему, и всё сделанное откатывается удалением одного файла.
- **Проблема — не в Chameleon.** Так «ворчит» на миллионы легитимных программ: AutoHotkey, System Informer (бывший Process Hacker) и десятки open-source утилит флагуют годами, и это не делает их вирусами.

## Почему антивирус подозревает файл (простыми словами)

**1. Один файл — это «самораспаковка».**
Чтобы программа работала без установки Python, exe при каждом запуске распаковывает себя во временную папку и стартует оттуда. Антивирус видит поведение: «файл распаковывается и запускается» — точно так же ведут себя вирусные дропперы. Совпало поведение, а не содержание, но эвристика не умеет читать намерения.

**2. У файла нет «паспорта».**
Цифровая подпись — это паспорт файла: она подтверждает, кто выпустил программу и что её не меняли после выпуска. Сертификат платный, поэтому у бесплатного проекта его пока нет — и антивирус по умолчанию смотрит на файл настороженно.

**3. Внутри всё сжато.**
Код программы внутри exe упакован, и сканер не может его прочитать. Часть антивирусов честно пишет в названии детекта: `Suspect.Packed` — то есть «запаковано, не вижу внутрь». Это не «нашёл вирус», это «не знаю, что там».

**4. Программа меняет файлы популярной игры.**
«Сторонняя программа пишет в папку Steam» — само по себе повод для подозрений. Хотя Chameleon просто кладёт рядом архив с ресурсами, и удаляется он без следов.

## Как читать результат VirusTotal

Смотри не на цифру «сколько движков заругалось», а на то, **какие** движки и **какие названия** детектов:

| Что видишь | Что это значит |
|---|---|
| 1–5 движков, названия вида `Generic`, `Heur.*`, `Suspect.Packed`, `Wacapew` | Классический ложняк: реакция на «неподписанный запакованный exe» |
| Детекты у мелких движков (Jiangmin, MaxSecureHost, Zillya...), а Defender, Kaspersky, ESET — чисты | Тоже ложняк: мелкие движки шумят на всё подряд |
| Десятки движков, включая Defender, Kaspersky, ESET, с конкретным названием семейства | Вот это плохой знак — к Chameleon не относится |

## Проверить самому за 5 минут

1. **Запусти без exe.** Скачай проект, установи зависимости (`pip install -r requirements.txt`), запусти `python run.py` — и вопрос «что внутри exe» исчезает сам собой.
2. **Собери свой exe.** Готовая команда сборки лежит в репозитории — файл, собранный у тебя на компьютере, по определению содержит только то, что есть в исходниках.
3. **Загляни в наш exe.** Onefile-архив PyInstaller открывается утилитой [pyinstxtractor](https://github.com/extremecoders-re/pyinstxtractor): внутри видны библиотеки и `.pyc`-файлы, которые декомпилируются в читаемый Python. Скрытого кода там нет — проверь сам.
4. **Сверь контрольную сумму** со значением из release-заметок:
   ```bat
   certutil -hashfile Chameleon.exe SHA256
   ```
5. **Прогони через VirusTotal** и оцени названия детектов по таблице выше, а не итоговую цифру.

## Как именно собран этот файл (честный список)

- официальный PyInstaller и стандартная команда сборки — её можно повторить по инструкции из репозитория и получить то же самое;
- один файл (onefile), **без UPX-сжатия** и без сторонних упаковщиков;
- без обфускации: код не прячется, ресурсы интерфейса лежат внутри обычными файлами;
- цифровой подписи пока нет (платный сертификат — в планах), поэтому часть эвристик может ворчать даже на полностью чистый файл.

## Если твой антивирус всё же сработал

1. Добавь файл в исключения — или (надёжнее всего) собери exe сам из исходников.
2. Отправь файл вендору как ложное срабатывание — это реально помогает всем пользователям проекта:
   - Microsoft (Defender): <https://www.microsoft.com/en-us/wdsi/filesubmission>
   - Kaspersky: <https://opentip.kaspersky.com/>
   - ESET: <https://www.eset.com/int/false-positive-report/>
3. Технические подробности — в официальной документации PyInstaller, раздел «Antivirus products»: <https://pyinstaller.org/en/stable/common-issues-and-pitfalls.html>

## FAQ

**Это вирус?**
Нет. Код открыт и проверяем, программа не внедряется в игру и не скрывает, что делает. Ложные детекты — побочный эффект упаковки Python-приложений в один файл, а не признак вредоносности.

**Почему VirusTotal ругается, если файл чистый?**
VirusTotal — это не приговор, а 70+ разных сканеров, включая агрессивные, которые пишут «подозрительно» на всё незнакомое и неподписанное. Несколько таких на новом exe — норма, а не сигнал опасности.

**Chameleon что-то отправляет в интернет?**
Всё сетевое поведение видно в открытых исходниках — его можно проверить так же, как и остальной код. Программа не содержит скрытых зашифрованных модулей.

**Почему нет подписи?**
Сертификат платный и требует подтверждения личности разработчика. Для бесплатного open-source проекта это заметные расходы. Подпись в планах — она уберёт и предупреждение SmartScreen, и большую часть ворчания эвристик.
