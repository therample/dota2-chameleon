# Code of conduct

Be kind, be specific, assume good intent. No harassment, no personal attacks, no spam.
Maintainers may remove comments or block people who break these rules. Disagreement about code is welcome;
contempt for people is not.

# Правила поведения

Будьте доброжелательны, выражайтесь конкретно и исходите из того, что у собеседника — благие намерения. Не допускаются домогательства, личные оскорбления и спам.
Администраторы могут удалять комментарии или блокировать пользователей, нарушающих эти правила. Разногласия по поводу кода приветствуются, а неуважительное отношение к людям - нет.
